====================================================================
Edge Impulse Studio 사용 가이드 (README)
====================================================================

본 폴더는 Edge Impulse Studio에서 학습 및 배포한 모델을 STM32 프로젝트에 적용하기 위한 파일입니다.

생성된 모델은 STM32 CubeIDE 프로젝트의 EdgeImpulse 폴더에 복사하여 사용합니다.

--------------------------------------------------------------------
1. 프로젝트 생성
--------------------------------------------------------------------

1) Edge Impulse Studio에서 Project 생성

2) Dashboard → Project Info

   Labeling method

      반드시

      Bounding boxes

   로 설정합니다.

   ※ Bounding boxes를 선택하지 않으면 FOMO(Object Detection) 학습이
      불가능합니다.

--------------------------------------------------------------------
2. 데이터 업로드
--------------------------------------------------------------------

Data acquisition 메뉴에서 데이터를 업로드합니다.

업로드 폴더 구성은 반드시 아래와 같이 합니다.

    train/
    test/

[중요]

validation(val) 폴더를 따로 업로드하면
Edge Impulse Studio에서 test 데이터와 자동으로 합쳐집니다.

따라서

    train + validation

을 하나의 train 폴더로 합친 후

    train
    test

두 개만 업로드해야 합니다.

업로드가 완료되면 Studio 내부에는

    Training
    Test

데이터셋이 생성됩니다.

Training 데이터는 이후 학습 시 Validation 비율을 지정하여
자동으로 분할됩니다.

--------------------------------------------------------------------
3. Impulse 생성
--------------------------------------------------------------------

Create Impulse 메뉴에서 아래와 같이 설정합니다.

    Input Size
        96 x 96

    Data
        Image

    Learning Block
        Object Detection

--------------------------------------------------------------------
4. Image 설정
--------------------------------------------------------------------

Image 메뉴에서

    - Color Depth
        RGB 또는 Gray Scale

등 필요한 전처리 옵션을 설정합니다.

--------------------------------------------------------------------
5. 모델 학습
--------------------------------------------------------------------

Object Detection 메뉴에서

    - Model 선택
    - Epoch
    - Learning Rate
    - Batch Size
    - GPU 사용 여부
    - Validation 비율

등을 설정한 후 학습을 진행합니다.

==========================
반드시 확인할 사항
==========================

(1)

Profile INT8 model

반드시 체크합니다.

체크하지 않으면
학습 후 INT8 양자화 모델이 생성되지 않습니다.

체크하면

    Float32 모델
            ↓
    INT8 Quantization
            ↓
    INT8 모델 생성

까지 자동으로 수행됩니다.

(2)

Edge Impulse Studio에서는

    - Epoch
    - Learning Rate
    - Batch Size
    - GPU
    - Validation 비율

정도만 조정 가능합니다.

모델 구조나 세부 학습 과정은 직접 수정할 수 없습니다.

(3)

학습 시 메모리 제한이 존재합니다.

실제 사용 결과

    약 20,000장 이하 데이터 기준

에서

    Epoch 10 ~ 25

정도가 현실적인 한계였습니다.

데이터가 많아질 경우

    전처리
    학습

단계에서 메모리 부족으로 학습이 시작되지 않을 수 있습니다.

==========================
참고
==========================

위와 같은 제약 때문에

TensorFlow 기반 로컬 학습/양자화 Pipeline을 별도로 구축하였습니다.

자세한 내용은

    FOMO_Local/README

를 참고하시기 바랍니다.

--------------------------------------------------------------------
6. 학습 결과 확인
--------------------------------------------------------------------

학습이 완료되면

오른쪽 결과 화면에서

    Float32 모델

    INT8 모델

각각의 성능 결과를 확인할 수 있습니다.

--------------------------------------------------------------------
7. Model Testing
--------------------------------------------------------------------

Model Testing 메뉴에서

Test Dataset을 이용하여 성능을 확인합니다.

==========================
반드시 확인할 사항
==========================

좌측

    Test data 옆의 Classify all

옆의

    톱니바퀴(Settings)

를 클릭합니다.

그리고

    Test 'Quantized (INT8)' model

을 반드시 체크합니다.

체크하지 않으면

Float32 모델만 테스트됩니다.

체크해야만

Float32

+

INT8

두 모델 모두 테스트되어 결과를 비교할 수 있습니다.

--------------------------------------------------------------------
8. Deployment
--------------------------------------------------------------------

Deployment 메뉴에서 아래와 같이 설정합니다.

Deployment Target

    C++ Library

Inference Engine

    EON Compiler

Model

    Quantized (INT8)

을 선택한 후

Build

버튼을 클릭합니다.

빌드가 완료되면

압축 파일이 다운로드됩니다.

--------------------------------------------------------------------
9. STM32 프로젝트 적용
--------------------------------------------------------------------

압축을 해제한 후

아래 3개 폴더만

CubeIDE 프로젝트의

EdgeImpulse

폴더에 복사합니다.

    edge-impulse-sdk
    model-parameters
    tflite-model

==========================
매우 중요
==========================

edge-impulse-sdk

안의

    porting

폴더에서

다음 항목만 남기고 모두 삭제합니다.

    stm32-cubeai/
    ei_classifier_porting.h
    ei_logging.h

나머지 파일은 삭제해야 STM32 프로젝트에서 정상적으로 사용할 수 있습니다.

--------------------------------------------------------------------
10. 모델 연동
--------------------------------------------------------------------

모델 복사가 완료되면

STM32 프로젝트에서

테스트 코드를 작성하여

모델 추론(Inference) 및 연동 테스트를 진행하면 됩니다.
